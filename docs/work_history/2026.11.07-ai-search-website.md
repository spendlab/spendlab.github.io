## Language and search behavior

- The neutral root contains full English HTML and redirects only at `/` or `/index.html`. The 16 explicit language URLs never auto-redirect to another language.
- `navigator.languages` selects the first supported preference. The manual choice is stored locally when available; blocked storage does not prevent navigation. Browser language and local preference are not transmitted to another service.
- Manual links work without JavaScript, and localized HTML includes its full content before any script runs. Query parameters and section fragments survive locale navigation.
- All language pages link to the one unchanged `/privacy/` page, using the unchanged label Privacy. Its source and shared assets have no new locale behavior.
- Canonical and alternate-language links, a static sitemap, and a sitemap-only robots file describe the actual pages. They do not guarantee crawling, AI citation or installation growth.
